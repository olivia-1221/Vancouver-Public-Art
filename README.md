# Exploring Vancouver Public Art by Neighbourhood

* `dsciproposal.ipynb` and `proposal.ipynb` contain our preliminary exploratory data analyses.
* `project.ipynb` contains our final report with difference-in-means hypothesis testing comparing the installation year of the art in Downtown and Mount Pleasant.
* We used data from the City of Vancouver's [Open Data Portal](https://opendata.vancouver.ca/pages/home/), which has information on the location, artist, and installation date of official public art within different neighbourhoods from the early 1900s to 2022.
