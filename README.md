# Exploring Vancouver Public Art by Neighbourhood

* `dsciproposal.ipynb` and `proposal.ipynb` contain our preliminary exploratory data analyses.
* `project.ipynb` contains our final report with difference-in-means hypothesis testing comparing the installation year of the art in Downtown and Mount Pleasant.
* We used data from the City of Vancouver's [Open Data Portal](https://www.google.com/url?sa=t&rct=j&q=&esrc=s&source=web&cd=&cad=rja&uact=8&ved=2ahUKEwj69K7_zZr7AhWzAjQIHdxLDqYQFnoECBoQAw&url=https%3A%2F%2Fwww.destinationvancouver.com%2Factivities%2Fsightseeing%2Fpublic-art-mini-guide%2F&usg=AOvVaw1C7YOKtvv8kVHkkdl_XYie), which has information on the location, artist, and installation date of official public art within different neighbourhoods from the early 1900s to 2022.
